# A shares one piece

这是一个本地运行的 A 股短线市场观察与决策研究工作台（A股短线模型），用于整理市场数据、情绪周期、炒作偏好、题材结构和次日观察条件。

## 开发环境要求

- Node.js 22.12.0 或更高版本
- npm 10 或更高版本
- Windows x64（当前桌面安装包目标）
