# 主线选择逻辑普适性验证

> 历史验证声明：本文只验证题材主线证据，不代表交易许可或最终股票结果。当前正式输出必须再通过 `unifiedDecisionChain v3` 的全部严格链路。

## 场景1：当前情况（存储 vs 军工）
- 存储芯片：9板，无共振
- 军工信息化：6板，有共振
- **预期结果**：存储芯片（高连板优先）
- **实际结果**：✅ 存储芯片

## 场景2：假设明天（人形机器人 vs 光伏）
- 人形机器人：5板，有共振，梯队完整
- 光伏：8板，无共振
- **预期结果**：光伏（高连板优先）
- **逻辑**：8板 > sustained(5板) ✅

## 场景3：假设后天（新能源车 vs 半导体）
- 新能源车：6板，有共振，梯队完整（sustained）
- 半导体：5板，有共振
- **预期结果**：新能源车（sustained优先）
- **逻辑**：sustained(6板) > 共振+连板(5板) ✅

## 场景4：冰点期（全市场只有3板）
- 题材A：3板，有共振
- 题材B：2板，有共振
- **预期结果**：题材A（连板高的）
- **逻辑**：都不满足≥4板，走共振+连板分支，按连板排序 ✅

## 场景5：主升期（多个高板）
- 题材A：10板，sustained
- 题材B：12板，无共振
- **预期结果**：题材B（更高板）
- **逻辑**：12板 > 10板，都在高连板分支(≥7) ✅

## 逻辑的自适应性

### 1. 连板高度阈值
```javascript
// 当前固定阈值
veryHigh: 7板
medium: 4板

// 未来可以改成动态阈值
veryHigh: max(全市场最高板 * 0.7, 5)  // 最高板12，则7板以上算高
medium: max(全市场最高板 * 0.4, 3)   // 最高板12，则4-5板算中
```

### 2. 互斥规则扩展
当前：2个体系（军工 / AI算力）

未来可以添加：
- 新能源体系（新能源车 / 光伏 / 储能 / 锂电池）
- 生物医药体系（创新药 / CRO / 医疗器械 / 疫苗）
- 消费体系（白酒 / 食品 / 家电 / 零售）

**扩展方式**：直接在exclusiveGroups数组添加新对象即可。

### 3. 主线持续性追踪
当前：每天独立判断主线

未来可以添加：
- 如果昨天是存储芯片，今天仍是存储芯片 → "主线持续"
- 如果昨天是军工，今天切换到存储 → "主线切换，观察确认"
- 连续3天同一主线 → "强主线，可加大仓位"

## 配置化建议

为了让逻辑更通用，建议将关键参数配置化：

```javascript
// config/mainline-rules.js
module.exports = {
  // 互斥体系定义
  exclusiveGroups: [
    { name: "军工", concepts: [...] },
    { name: "AI算力", concepts: [...] },
  ],

  // 主线选择阈值
  thresholds: {
    veryHighLimit: 7,      // 高连板阈值
    mediumLimit: 4,        // 中连板阈值
    resonanceMinLimit: 2,  // 共振最低连板要求
    sustainedMinCount: 4,  // sustained最低count
    sustainedMinLimit: 2,  // sustained最低连板
  },

  // 优先级权重（备用方案：改成打分制）
  weights: {
    limitCount: 10,   // 每1板=10分
    resonance: 15,    // 共振=15分
    sustained: 25,    // 结构完整=25分
  },
};
```

## 总结

修复的**不是特例**，而是**通用逻辑**：

4. ✅ 优先级逻辑清晰（高连板 > 结构 > 中连板 > 单维度）
